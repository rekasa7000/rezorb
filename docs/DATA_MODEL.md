# Rezorb — Data Model

Postgres (Neon) with Drizzle ORM. All IDs are UUIDv7 (time-sortable) unless
noted. All timestamps are `timestamptz`.

## 1. Entity overview

```
user 1───* device
user 1───* space 1───* drop
space 1───* space_grant *───1 device
user 1───* session (Better Auth)  session *───1 device
```

## 2. Tables

### 2.1 Better Auth tables

`user`, `session`, `account`, `verification`, `passkey`, and `device_code` are
generated by Better Auth's Drizzle adapter (`npx @better-auth/cli generate`).
Rezorb extends them as follows:

- `user` adds: `storage_used_bytes bigint not null default 0`, `plan text not null default 'free'`.
- `session` adds: `device_id uuid references device(id) on delete cascade`.

### 2.2 `device`

| Column | Type | Notes |
|--------|------|-------|
| `id` | uuid PK | |
| `user_id` | uuid FK → user, cascade | |
| `label` | text | Auto-generated from the User-Agent, for example "Chrome on Windows". The user can rename it. |
| `kind` | text | `desktop` · `laptop` · `phone` · `tablet` · `unknown` |
| `created_at` | timestamptz | |
| `last_seen_at` | timestamptz | Updated at most once per 5 minutes |
| `revoked_at` | timestamptz null | Set when revoked. All sessions and grants are deleted at the same time. |

The device ID is also stored in a long-lived `rz_dev` cookie (HttpOnly, signed),
so signing out and back in on the same browser reuses the same Device.

Index: `(user_id) where revoked_at is null`.

### 2.3 `space`

| Column | Type | Notes |
|--------|------|-------|
| `id` | uuid PK | |
| `owner_id` | uuid FK → user, cascade | |
| `name` | text | 1–40 characters. Display name. |
| `name_key` | text | `lower(trim(name))`, used for lookup |
| `slug` | text unique | 10 characters, base58, random. Used in the URL. |
| `pin_hash` | text | Argon2id (`m=19456, t=2, p=1`, the OWASP baseline) |
| `pin_version` | int default 1 | Incremented on PIN change. Grants carry it. |
| `accent` | text | One of 8 accent tokens |
| `default_lifetime` | text | `1h` · `24h` · `7d` |
| `failed_attempts` | int default 0 | Reset on success |
| `lockout_count` | int default 0 | Drives the doubling lockout duration. Decays after 24h with no lockout. |
| `locked_until` | timestamptz null | |
| `encryption` | text default 'none' | `none` · `e2e_v1` (v2) |
| `kdf_salt` | bytea null | v2 E2E |
| `created_at`, `updated_at`, `last_activity_at` | timestamptz | |

Constraints and indexes:
- `unique (owner_id, name_key)`
- `index (owner_id, last_activity_at desc)`

### 2.4 `space_grant`

| Column | Type | Notes |
|--------|------|-------|
| `id` | uuid PK | The value stored, signed, in the `rz_g_{spaceId}` cookie |
| `space_id` | uuid FK → space, cascade | |
| `device_id` | uuid FK → device, cascade | |
| `user_id` | uuid FK → user, cascade | Denormalized for fast checks |
| `pin_version` | int | Must equal `space.pin_version` |
| `created_at` | timestamptz | |
| `expires_at` | timestamptz | Sliding: now + 12h on activity |
| `revoked_at` | timestamptz null | |

Index: `(space_id) where revoked_at is null`, `(device_id)`.

### 2.5 `drop`

| Column | Type | Notes |
|--------|------|-------|
| `id` | uuid PK (v7) | Sort order = creation order |
| `space_id` | uuid FK → space, cascade | |
| `source_device_id` | uuid FK → device, set null | |
| `kind` | text | `text` · `code` · `link` · `image` · `file` |
| `status` | text | `uploading` · `ready` |
| `text` | text null | For text, code, and link kinds. Max 1 MB. |
| `language` | text null | Detected code language (code kind) |
| `blob_key` | text null | R2 key `u/{userId}/s/{spaceId}/d/{dropId}/blob` |
| `thumb_key` | text null | R2 key for an image thumbnail |
| `file_name` | text null | Sanitized original name |
| `mime_type` | text null | |
| `size_bytes` | bigint | For text, the UTF-8 byte length |
| `width`, `height` | int null | Images |
| `pinned` | boolean default false | |
| `iv` | bytea null | v2 E2E |
| `created_at` | timestamptz | |
| `expires_at` | timestamptz | `created_at + lifetime`. If pinned, `created_at + 7d`. |

Indexes:
- `(space_id, id desc)`: feed pagination.
- `(expires_at)`: the burn job.
- `(status, created_at) where status = 'uploading'`: stale upload cleanup.

## 3. Invariants

1. `user.storage_used_bytes` = the sum of `drop.size_bytes` (plus thumbnail sizes)
   over that user's unexpired, ready drops. It is incremented on `complete`
   and decremented on burn **in the same transaction** as the row change. A
   nightly job recomputes it to correct drift.
2. A drop with `kind in (image, file)` has a `blob_key`. A drop with
   `kind in (text, code, link)` has `text`.
3. A grant is valid iff `revoked_at is null and expires_at > now()`, its
   `pin_version` equals the space's, and its device is not revoked.
4. Deleting a Space deletes its drops (cascade) **and** schedules deletion of the R2
   prefix `u/{userId}/s/{spaceId}/`. This is done in the request, with the cron
   job as backstop.

## 4. Drizzle sketch

```ts
// src/server/db/schema.ts (excerpt)
export const space = pgTable("space", {
  id: uuid("id").primaryKey().$defaultFn(uuidv7),
  ownerId: uuid("owner_id").notNull().references(() => user.id, { onDelete: "cascade" }),
  name: text("name").notNull(),
  nameKey: text("name_key").notNull(),
  slug: text("slug").notNull().unique(),
  pinHash: text("pin_hash").notNull(),
  pinVersion: integer("pin_version").notNull().default(1),
  accent: text("accent").notNull(),
  defaultLifetime: text("default_lifetime", { enum: ["1h", "24h", "7d"] }).notNull().default("24h"),
  failedAttempts: integer("failed_attempts").notNull().default(0),
  lockoutCount: integer("lockout_count").notNull().default(0),
  lockedUntil: timestamp("locked_until", { withTimezone: true }),
  encryption: text("encryption", { enum: ["none", "e2e_v1"] }).notNull().default("none"),
  kdfSalt: bytea("kdf_salt"),
  createdAt: timestamp("created_at", { withTimezone: true }).notNull().defaultNow(),
  updatedAt: timestamp("updated_at", { withTimezone: true }).notNull().defaultNow(),
  lastActivityAt: timestamp("last_activity_at", { withTimezone: true }).notNull().defaultNow(),
}, (t) => [uniqueIndex("space_owner_name").on(t.ownerId, t.nameKey)]);
```

## 5. Migrations

- Run `drizzle-kit generate` to create SQL in `src/server/db/migrations`. These
  files are committed.
- `drizzle-kit migrate` runs in the Vercel **build step**
  (`pnpm db:migrate && next build`) against the environment's `DATABASE_URL_UNPOOLED`.
- Migrations must be backward compatible with the previous deployment, using the
  expand/contract pattern, because preview and production can overlap.
